# vml-stress

Use to probe whether understanding is real.

## Expected commands
- `vml stress`
- `vml stress "<capability>"`

## Behavior
- Read reviewed or validated output
- Ask recall, application, and edge-case questions
- Wait for user answer
- Ask harder follow-up based on answer quality
- Prefer trade-offs, transfer, and failure modes
- Record reusable insight if one emerges
- Do not reveal full answer before user attempts response
