## Variant: Red chrome

### Design stance
Code goes monochrome Osaka grays + cream; red is reserved for "where am I" chrome and real errors.

### Key choices
- Syntax: keyword fg italic, function/type base1, string cream; no red in code
- Search: dark text on cream base2 (never confused with errors)
- Red only: focus border, active tab, normal mode, cursor line nr, prompt `◇`, yazi mode badge, errors (red300)

### Trade-offs
- Strong at: calm; red always means focus or error; long-session friendly
- Weak at: code has few hue cues (relies on italic + brightness)

### Best for
- Long editing; Gin's "too hot" feedback
