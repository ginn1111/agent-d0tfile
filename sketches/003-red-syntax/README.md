## Variant: Red syntax (current `agent-tool-themes/cindy`)

### Design stance
Red is both brand and code: keywords red500, chrome red500, search red700, errors red300.

### Key choices
- Syntax: keyword red, function/type base1, string cream base2
- Search: cream on red700
- Chrome: base03 surfaces, red focus/tab/mode

### Trade-offs
- Strong at: strongest Cindy identity inside the editor
- Weak at: keyword/error/search all red; busy code; hot

### Best for
- Short sessions where identity beats calm
