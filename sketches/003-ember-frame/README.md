## Variant: Ember frame

### Design stance
Red lives in the frame, dark: bars/borders/selection in red950/red900; editor body stays Osaka teal; keywords deep red700.

### Key choices
- Chrome: red950 tab/status bars, red900 borders, active tab red300 text on red900 chip
- Syntax: keyword red700 (dim, not hot), function base1, string cream
- Search: cream text on base02 teal with outline

### Trade-offs
- Strong at: matches Hermes skin's red-tinted darks; identity from edges, not text
- Weak at: two background temperatures (red frame, teal body) can look muddy

### Best for
- Running Hermes TUI next to tools; one continuous ember surface
