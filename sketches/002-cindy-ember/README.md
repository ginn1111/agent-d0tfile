## Variant: Cindy Ember (Solarized Osaka bases + red ramp)

### Design stance
Solarized Osaka structure (teal-dark bg, slate grays) kept; Osaka red ramp (red300/500/700/900/950) is the only accent. Green/yellow survive only as ok/warn/git signals.

### Key choices
- Palette: `agent-tool-themes/cindy/cindy-ember.palette`
- Syntax: keyword red500, function/type base1, string base2 cream, comment base01
- Chrome: base03 surfaces, red500 focus/active tab, red900 glow

### Trade-offs
- Strong at: familiar Osaka feel; Cindy identity via red only
- Weak at: fewer hue cues in code; errors (red300) close to keywords (red500)
